Overview

This project implements a **baseline evaluation pipeline** for a Large Language Model (LLM) using a golden question set. The model is evaluated using **keyword-based scoring** to measure how well it answers predefined questions.

The evaluation runs against a local LLM served via [Ollama](https://ollama.ai/) and produces a structured CSV report.

//How It Works

The evaluation pipeline has 8 steps:

Step - Description 
 1 - Configuration (model, file paths) 
 2 - Load golden question set from `golden_set.json` 
 3 - Send each question to the LLM via Ollama REST API 
 4 - Keyword-based scoring of LLM responses 
 5 - Run baseline evaluation loop 
 6 - Save results to `baseline_results.csv` 
 7 -  Print evaluation summary 
 8 - Completion confirmation 

### Scoring Logic

Each answer is scored by checking how many **expected keywords** appear in the LLM's response:

```
Score = (Matched Keywords / Total Keywords) × 100
```

- **PASS**: Score ≥ 60%
- **REVIEW**: Score < 60%
- **ERROR**: Request failed

---

 Output: `baseline_results.csv`

 Column -  Description 
 `Question_ID`  Unique identifier for each question 
 `Question`  The question posed to the LLM 
 `Expected_Answer`  Reference answer from the golden set 
 `LLM_Answer`  Response generated by the model 
  `Matched_Keywords` Keywords found in the response 
  `Missing_Keywords`  Keywords not found in the response 
  `Score` Keyword coverage score (%) 
  `Status` PASS / REVIEW / ERROR 
  `Source`  Source category of the question 
 `Model`  Model used (`llama3.2`) 
  `Release`  Evaluation release version (`v0.1`)
